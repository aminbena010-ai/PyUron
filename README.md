# PyUron 0.1

Motor de videojuegos modular, Python-first, 2D y 3D.
Este primer hito establece: ventana (Pygame-ce), contexto OpenGL 3.3
Core, bucle principal y renderer minimo.

## Requisitos
- Python 3.12+
- GPU/driver con soporte OpenGL 3.3+

## Instalacion
    python -m venv .venv
    source .venv/bin/activate   # Windows: .venv\Scripts\activate
    python -m pip install --upgrade pip
    python -m pip install -e .

## Ejecutar
    python main.py
